Яндекс Облако: регистрация и что прислать

1. Зарегистрироваться

  1. Открыть cloud.yandex.ru → Зарегистрироваться → подтвердить телефон по SMS.
  2. Создать платёжный аккаунт → привязать банковскую карту (100 ₽ депозит возвращается; новым аккаунтам дают 4000 ₽ гранта).

2. Создать каталог

  1. Открыть console.cloud.yandex.ru.
  2. Сверху слева выпадающий список каталога → Создать каталог → имя tea-shop → создать.

3. Создать сервисный аккаунт и ключ

  1. В консоли: Сервисы → IAM → Сервисные аккаунты → Создать сервисный аккаунт → имя deploy → роль editor на каталог tea-shop → создать.
  2. Нажать на созданный аккаунт deploy → вкладка Ключи → Создать авторизованный ключ → скачается файл key.json. Важно: именно «авторизованный ключ» (файл), а не «статический ключ доступа» (тот не подходит для деплоя — он только для S3-хранилища) и не «API-ключ» (им нельзя деплоить, только вызывать сервисы).
Что прислать разработчику (владельцу этой инструкции):
1. Файл key.json из шага 3 (или его содержимое целиком — там длинный ключ, начинается с -----BEGIN PRIVATE KEY-----).
2. ID каталога: на главной консоли, в строке каталога tea-shop, кнопка копирования под названием (выглядит как b1g...).
3. Всё. Токены МойСклада, СДЭК и Т-Банка — позже, когда дойдём до этих шагов.

СДЭК: регистрация и что прислать

1. Заключить договор

  1. Открыть cdek.ru/business → Стать клиентом (или «Подключить доставку»).
  2. Заполнить заявку: ИНН, контакты. Договор заключается дистанционно, без визита в офис.
  3. Дождаться письма со СДЭК с доступом в личный кабинет (обычно 1–3 рабочих дня).
Доступ к API бесплатный — платится только сама доставка.

2. Получить ключи API

  1. Войти в личный кабинет: lk.cdek.ru.
  2. Открыть раздел Интеграция: lk.cdek.ru/integration/index.
  3. Нажать Создать ключ.
  4. Система выдаст пару: Идентификатор аккаунта (client_id) и Пароль (client_secret). Скопировать оба сразу.
Это НЕ логин и пароль от личного кабинета — отдельная пара специально для программного доступа. Если раздел «Интеграция» недоступен — написать на integrator@cdek.ru, ключи пришлют на почту.

3. Решить про отгрузку

  1. Определить, откуда посылки: ближайший склад СДЭК в вашем городе (привоз самостоятельно) или курьерский забор с вашего адреса.
  2. Написать разработчику, какой вариант выбран.
Что прислать разработчику:
1. client_id и client_secret (шаг 2).
2. Город и адрес, откуда отправлять посылки + вариант: склад/курьерский забор (шаг 3).
3. Всё. Разработка начнётся сразу на тестовом контуре СДЭК — ключи нужны только для запуска в бой.
